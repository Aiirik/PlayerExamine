# Player Examine

RS3-inspired equipment overlay for RuneLite.

## Features

- Adds a right-click `Examine` option for other players
- Opens a movable overlay after examining a player
- Includes `Default`, `List`, and `Hybrid` overlay modes
- Renders a RuneScape-style equipment layout in `Default` mode
- Shows a compact text list in `List` mode
- Shows a compact text list with icons in `Hybrid` mode
- Dynamically sizes `List` and `Hybrid` layouts to the content
- Supports hiding slots marked `Not visible from examine` in list-based modes
- Uses hover tooltips for item names and grouped GE / HA values
- Supports GE value, HA value, and total value display
- Supports opening the OSRS wiki from an item slot
- Supports hiding or showing the `(Members)` suffix
- Includes configurable overlay, slot, and text colors
- Includes login update notices
