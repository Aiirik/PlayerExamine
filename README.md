# Player Examine

RS3-inspired equipment overlay for RuneLite.

## Features

- Adds a right-click `Examine` option for other players
- Opens a movable equipment overlay in a RuneScape-style frame
- Shows the examined player's visible worn items
- Uses hover tooltips for item names
- Supports GE value and high alch value tooltips
- Supports opening the OSRS wiki from an item slot
- Supports hiding or showing the `(Members)` suffix
- Includes configurable overlay colors
- Includes login update notices
